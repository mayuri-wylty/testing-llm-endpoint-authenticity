Areas: core, headers, longctx, reasoning, tokenizer, messages, responses, matrix (3 protocols x 9 scenarios; `selftest_matrix.py` checks cross-protocol consistency). New protocols: add `protocol_args` there (e.g. `--protocol anthropic --path /messages`).
